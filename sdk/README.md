# QuoteScribe SDKs

Official client libraries for the QuoteScribe public REST API.

| Language   | Directory        |
|------------|------------------|
| TypeScript | `./typescript/`  |
| Python     | `./python/`      |

The full API reference is served in-app at `/developers`.
Generate an API key at **Settings → API** inside the app.

## Base URL

```
https://your-app.example.com/api/public/v1
```

## Auth

Bearer token in the `Authorization` header:

```
Authorization: Bearer qsk_live_...
```
